# 塾の授業管理システム（試作版）

個別指導塾を想定し、生徒ごとの授業回数の管理と授業の振替を扱う
学習用のプロジェクトです。Pythonで業務処理を実装し、SQLiteに
授業予定や授業回数の増減履歴を保存しています。

## 実装した機能

- 生徒ごとの月次授業回数の付与と、同じ月への二重付与の防止
- 授業の完了に伴う残り授業回数の消化
- 授業の振替と、振替元・振替先の関連付け
- 生徒の授業予定が重複する時間枠への振替の拒否

## 実装・テストで工夫した点

振替を拒否した際は、エラーメッセージに加えて、振替元が予約済みのまま残り、
振替先にも授業が追加されていないことをテストで確認しています。
生徒の重複を検証するケースでは、振替先と予約済みの授業で講師を変え、
生徒の予定が重なる条件を作っています。

## 主なファイル

| ファイル | 内容 |
| --- | --- |
| `init.py` | SQLiteのテーブルとサンプルデータの初期化 |
| `grant_monthly_lessons.py` | 月次授業回数の付与 |
| `complete_lesson.py` | 授業の完了処理 |
| `reschedule_lesson.py` | 授業の振替処理 |
| `test_business_logic.py` | pytestによる業務処理のテスト |

## テストの実行

リポジトリを取得し、プロジェクトのディレクトリで以下を実行します。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
```

開発環境（WSL / Ubuntu）で11件のテストが通過しました。
